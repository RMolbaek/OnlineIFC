# Security policy

Vispecta runs entirely in the browser: IFC, IDS and BCF files are opened and processed on your own computer and are never uploaded. Still, a flaw in how a file is read, or in the site itself, could matter. Thank you for reporting it.

## Reporting a vulnerability

Please report it privately, not in a public issue:

- **GitHub:** [report a vulnerability](https://github.com/vispecta-app/vispecta/security/advisories/new) (private to the maintainers), or
- **E-mail:** contact@vispecta.com

Tell us what you found, how to reproduce it (a small IFC file helps), and which browser you used. You will get an answer within a week. Once a fix is out, we are glad to credit you in the release notes if you like.

## Supported versions

Only the current version at https://vispecta.com is supported; it is updated from the `main` branch.
